# 配图复核 · 实测裁定表（mit-6.5840）

**这张表做什么**：`check_reviewed.py` 读它，把「已被实测证伪的复核结论」从阻塞列表里移出。
**规则见 `courselingo/docs/quality-audit.md` 附录八 / 附录十一 / 附录十二。**

## 写入规矩

| 列 | 要求 |
| --- | --- |
| 图 | 图名（本轮用的是复核报告的文件名里的 stem） |
| 原判定 | 复核报告的结论 |
| 裁定 | 只认 `可用` |
| 依据（实测值） | **必须含数字**，且**必须粘属性原文或量到的值** |
| 裁定人 | 谁裁的 |
| 针对报告 | **那份复核报告的 SHA256 前 16 位**（归一化后） |

**★ 为什么必须钉报告哈希**：裁定是「**对某一次判定的反驳**」，不是「对这张图的永久结论」。
报告比裁定新 ⇒ **裁定不适用**，按新报告处置。
（实测教训：我先用 mtime 判，本地过、CI 红 —— **干净检出里 git 把所有文件 mtime 设成同一时刻，同仓内比 mtime 无意义**。）

**★ 为什么依据必须粘原文**：否则「**我读了属性**」和「**我目测了**」在记录里**长得一模一样**。

复核者称：「第二组标题写『**两个**已经被明确记下来的取舍』，但其下**并列三张**同等地位的卡片，

**核实**：标题 `x=380 y=204` 写「两个已经被明确记下来的取舍」，其下 `y=216` 确实**并列三张** `w=209` 的卡片
（`x=38/275/512`）。

**⇒ 这条成立，归 `附录十`（图的排版在替文字下结论）** —— **三张卡片「并列」这个排版本身在断言它们是三件平级的事**，
而标题说其中两件属于同一个取舍 ⇒ **排版否定了文字**。

**本表的裁定只覆盖第一条（几何），不覆盖这一条** —— 按 `附录十一` 四补：
**裁掉的是它给的数，不是它指的事。**
