## 陌生读者测试（8 题）

1. 复制能对付哪类失效、对付不了哪两类？答：停止型；对付不了缺陷 / 人为误操作（可能相关）与大范围失效（除非副本分开）。
2. 复制状态机的四个条件？答：同初始状态、同操作、同顺序、确定性。
3. 为什么自动切换主机很难？答：崩了与网断了对客户端不可区分。
4. Raft 在副本里是什么形态？答：一个库，分键值层与 Raft 层。
5. 一条命令从进入到被执行经过哪几步？答：进键值层 → Start → 追加日志 → AppendEntries → 多数派 → 捎带提交并执行。
6. 一个任期里为什么至多一个领导者？答：要多数票，且每台每任期只投一票。
7. 分裂投票为什么几乎必然、怎么破？答：超时几乎同时到期且都投自己，加随机量打破对称。
8. 老领导者为什么不会脑裂、代价是什么？答：要么看到更高任期退位，要么拿不到多数因而不能提交；代价是尾部可能分叉。

8 题都能在页面里直接找到答案（依次在第 1、2、3、3、3、7、9、10 节）。
